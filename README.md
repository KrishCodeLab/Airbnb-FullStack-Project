# Airbnb Clone

## Overview

An Airbnb-inspired full-stack web application developed using Node.js, Express.js, EJS, and MongoDB.

The application allows users to explore property listings and manage listing data through CRUD operations. The frontend is built using EJS templates and Bootstrap to provide a responsive user interface across different screen sizes.

## Tech Stack

**Frontend**
- EJS (Embedded JavaScript Templates)
- HTML5
- CSS3
- Bootstrap

**Backend**
- Node.js
- Express.js
- Express Routing
- Nodemon

**Database**
- MongoDB

## Features

- Responsive user interface built with Bootstrap.
- Dynamic page rendering using EJS templates.
- Express.js routing for application navigation.
- MongoDB database connectivity.
- Create new property listings.
- View existing property listings.
- Update listing details.
- Delete property listings.
- Server-side handling of application requests.

## CRUD Operations

| Operation | Description |
|---|---|
| Create | Add new property listings |
| Read | Display existing listings |
| Update | Modify listing information |
| Delete | Remove property listings |

## Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project directory

```bash
cd airbnb-clone
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file in the root directory.

```env
PORT=3000
MONGODB_URI=your_mongodb_connection_string
```

### 5. Start the application

```bash
npm start
```

For development using Nodemon:

```bash
npm run dev
```
